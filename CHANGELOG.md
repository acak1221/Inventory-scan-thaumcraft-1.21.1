# Изменения

## 1.0.2+1.21.1 — 01.11.2026

- Снято требование ровно Thaumcraft 4 Reload `0.1.0-alpha.7`: зависимость в метаданных Fabric и NeoForge теперь `*`.
- Из описаний загрузчиков убрано указание только alpha.7. Поведение сканирования не менялось.
- Обновлены готовые JAR, контрольные суммы и сведения о проверках.

Minecraft остаётся строго 1.21.1. Нужны Java 21, Fabric Loader ≥0.16.14 либо NeoForge ≥21.1.259, Architectury API ≥13.0.11; на Fabric также Fabric API. Другие версии Thaumcraft должны сохранять вызываемый аддоном API.

Проверено с Thaumcraft 4 Reload alpha.7 из коммита `4c38e3f3bb44c3455718d8f3e04073921ec2a932`: обе production-сборки и проверки изоляции JAR, 6 JUnit-тестов, по 13 серверных GameTests на Fabric и NeoForge. Игровой клиент, удалённый мультиплеер и другие версии Thaumcraft для этого выпуска не проверялись.
